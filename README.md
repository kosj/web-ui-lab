# web-ui-lab

운영·관제 대시보드 UI 실험실. 보드를 하나씩 만들며 디자인 시스템과 분석 지식을 쌓는다.

## 보드

### 렉 보드 (`boards/lag-board`)
가상 MMORPG의 6개 글로벌 권역·36개 서버에서 체감 렉 추이를 보고, 렉 원인을 **인프라 / 네트워크 / 서버 / 클라**로 판별하는 보드.

- **체감 지연(EL)**: RTT·지터·손실·서버 틱·클라 프레임을 ms 하나로 환산
- **등급**: 쾌적 <100 · 양호 100–150 · 주의 150–250 · 경고 250–500 · 심각 ≥500ms ([근거](knowledge/lag-thresholds.md))
- **판별**: 전일 동시간대 기준선, MAD 강건 z, EWMA, CUSUM, 랙·권역·통신사 확산 패턴
- **통신사 드릴다운**: 권역 × 통신사 경로 매트릭스, 통신사별 RTT·지터·손실·전일 대비, 장애 범위를 통신사로 좁힘
- **지연 분포 히트맵**: 유저 단위 체감 지연을 로그 구간 밀도로 표시, 두 갈래(일부 집단만 렉) 자동 안내
- **유저 체감 신호**: 채팅 렉 제보 × TCP 재전송 × 체감 지연 — 신호 연쇄, 사건 동시발생 분석, 사건 정렬 평균, 장애 지도, 용량–반응(제보가 꺾여 오르는 체감 지연), 측정 사각지대 탐지 ([방법](knowledge/user-signals.md))
- **스타일 5종**: 그래파이트 · 콕핏(항공 글래스 콕핏, B612) · 터미널(앰버 인광) · 에디토리얼(스위스 그리드) · 글래스 — 상단 메뉴로 전환, `#style-<id>`로 공유 ([비교 갤러리](docs/style-gallery/index.html), [근거](knowledge/styles.md))
- **모션**: 장애 재생(시간 커서 자동 진행·미래 흐림), 롤링 숫자, 등급 상승 링, 통신사 패킷 흐름(RTT·지터·손실 인코딩), 드릴다운 뷰 전환. 상단 토글로 전체 정지 ([모션 가이드](knowledge/motion.md))
- **가상 장애 5건 + 제보 시나리오 2건**: 서버 틱 지연(JP-03), 동남아 해저 케이블(다중 통신사), LG U+ 국제망 우회(단일 통신사), 클라 2.14.0 프레임 스톨, 서울 DC 랙 R2 호스트 경합, 대만 던전 로딩(측정 사각지대), 북미 도배. 원인·범위·시작 시각·제보 결합을 테스트로 검증

## 구조
```
design-system/      공용 디자인 토큰 (다크 우선, 라이트 지원)

knowledge/          레퍼런스 조사, 임계값 근거, 학습 로그
.claude/skills/     축적된 제작 지식 (ops-dashboard-design, lag-analytics)
tools/              시각 QA 도구
```

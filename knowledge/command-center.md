# 커맨드 센터 — 화려하고 동적인 관제 화면

> 2026-11-14. 질문: "배치와 스타일을 완전히 바꿔 줄 수 있어? 화려하고 동적인 스타일은 어때? 레퍼런스 찾아서 최상급으로 재구성해줘"
> 구현: `boards/lag-board/src/command/` (CommandCenter · WorldFlowMap · LagGauge · CauseEqualizer · IncidentFeed · RegionPods · TimelineRibbon · geo · palette · command.css)
> 데모 영상: `docs/media/command-center.mp4` (등장 → 권역 선택 → 동남아 케이블 장애 재생 → 최근 3시간 재생)

## 1. 결론 — "화려함"을 데이터가 만들게 한다

- **화면을 새로 하나 만들었다.** 기존 보드는 "분석 보드"로 한 번의 클릭 거리에 둔다.
  - 커맨드 센터는 관제실 벽용 한눈 화면, 분석 보드는 원인 판별·근거용 깊은 화면이다.
  - 같은 모델·재생 엔진을 쓰고 배치·표현만 다르다.
  - 주소: `#command`(기본) · `#analysis` · `#style-<id>`(분석 보드 + 스타일). v0.7에서 세 번째 후보 `#broadcast`(라이브 중계, `knowledge/broadcast.md`)가 추가됐다.
- **움직이는 것은 전부 측정값이다.**
  - 입자 속도는 RTT, 흩어짐은 지터, 사라짐은 손실이다.
  - 대륙 점의 물듦은 권역 등급, 소나 링은 진행 중 장애, LED 칸은 원인별 초과 지연이다.
  - 모션을 끄면 같은 인코딩의 정지 화면이 된다. 경로선과 화살촉, 손실 경로는 점선, 장애는 정지 링 두 겹이다.
- **크롬은 낮은 불투명도의 시안, 강한 색은 상태에만 쓴다.**
  - 네온 HUD 느낌은 테두리·모서리 눈금·발광(번짐)으로 낸다. 색 수를 늘리지 않는다.

## 3. 배치

```
HUD: 브랜드 · [커맨드 센터 | 분석 보드] · 수집 상태 · LIVE/재생/과거 시계 · 모션
┌ 레일 296px ───────┬ 세계 흐름 지도 (주인공) ─────────────────────────┐
│ 체감 지연 게이지  │  점묘 대륙 · DC 노드 · 통신사 위성 · 입자 흐름    │
│ 2×2 수치          │  지역 카드(자동 배치) · 전역 장애 띠(머리)        │
│ 원인 이퀄라이저   │  등급 범례                                        │
├ 장애 피드 ────────┴─┬ 권역 포드 3×2 ─────────────────────────────────┤
├ 24시간 타임라인 리본 (전체 p95 · 권역 6줄 · 원인 4줄 + 사각지대) ─────┤
```

- **읽는 순서:** 레일은 "얼마나 나쁜가", 지도는 "어디가", 피드·포드는 "무엇이", 리본은 "언제"를 답한다.
- **권역 선택:** 지도 노드나 포드로 권역을 고르면 게이지·이퀄라이저·피드·리본이 모두 그 권역으로 좁혀지고, 다른 권역은 흐려진다.
- **넘겨주기:** 피드의 "분석 보드" 버튼은 그 장애를 고른 채 분석 보드를 연다(`Handoff`). HUD의 전환 버튼은 고른 권역을 넘긴다.
- **반응형:**
  - ≤1240px에서는 레일이 지도 위 가로 3칸이 된다.
  - ≤1080px에서는 피드와 포드가 세로로 쌓인다.
  - ≤640px에서는 한 줄이고, 지도는 1.7:1이다.

## 4. 표현 규칙

### 지도 (`WorldFlowMap`, `geo.ts`)

- **투영:** Natural Earth I을 동경 18° 중심으로 쓰고, 서경 130°~동경 190°, 남위 40°~북위 70°를 화면에 맞춘다(d3-geo).
  - 상자가 더 높으면 폭에 맞춘 채 위도를 더 보여 준다. 빈 띠를 남기지 않기 위해서다.
- **대륙:** world-atlas land-110m을 오프스크린 캔버스에 칠한 뒤, 육각 격자로 표본을 뽑아 점묘로 만든다.
- **변위 일반화:** 동아시아 세 DC(인천·나리타·타오위안)는 수십 px 안에 몰린다.
  - 노드를 빈 공간으로 옮기고, 실제 위치에는 흰 점과 등급색 고리를 남긴 뒤 지시선으로 잇는다.
  - 지시선은 궤도 바깥에서 끊는다(궤도 안은 입자 공간이다).
- **입자:** 분석 보드의 패킷 레인과 같은 인코딩이다.
  - 통과 시간은 0.25s + RTT p50/80 (최대 4s)이다.
  - 흩어짐은 지터/RTT이다.
  - 손실은 실제 손실률 × 5배 확률로, 빨간 불꽃을 남기고 사라진다.
  - 색은 그 통신사 유저의 체감 지연 추정 등급이다.
  - 동시에 떠 있는 입자 수는 통신사 유저 비중에 비례한다.
- **통신사 이름:** 이상 경로(z ≥ 3 그리고 +15ms)이거나 선택된 권역일 때만 단다. 이상 경로에는 "PLDT +481ms"처럼 증가분을 쓴다.
- **장애 소나:** 진행 중 장애가 있는 노드에서 원인색 링이 2.4초 주기로 두 겹 퍼진다.
  - 통신사 범위 장애는 그 위성에서 울린다.
  - 전역(클라 버전) 장애는 지도 머리의 띠로 표시한다(한 점이 아니므로).
- **지역 카드 배치 (`placeCards`):** 탐욕적 라벨 배치를 쓴다.
  - 후보는 8방향과 한 단계 먼 8방향이다.
  - 벌점은 지도 밖, 다른 카드, 다른 노드 궤도, DC 실제 위치 표식, 선호 방향 순위 순으로 무겁다.
  - 카드 크기는 배율(u)별 3단(full 108×70 / mid 92×46 / compact 70×32)이다.
  - 회귀 테스트는 `src/command/__tests__/geo.test.ts`(8개 크기)이다.
- **층:** 정적 층과 움직이는 층으로 나눈다.
  - 정적 층(점·물듦·지시선·위성·노드)은 시점·범위가 바뀔 때만 다시 그린다.
  - 움직이는 층(입자·불꽃·소나)은 rAF로 그리고, 화면 밖이거나 탭이 숨겨지면 멈춘다.
  - 1440×900에서 60fps를 확인했다.

### 게이지 · 이퀄라이저 · 피드 · 포드 · 리본

- **게이지:**
  - 240° 호에 등급 경계 기준 구간 선형 눈금을 쓴다(0·100·150·250·500·800 → 0·25·40·60·85·100%). 운영자가 보는 100~500ms 구간이 넓어진다.
  - 바깥 띠는 등급 구간, 안쪽 호는 현재 값(발광)이다.
  - 등급이 오를 때만 링이 한 번 퍼진다(`useEscalation`).
- **이퀄라이저:**
  - 원인 4개를 LED 12칸, 로그 눈금 2–320ms로 그린다.
  - 흰 칸은 최근 15분 최대값이다. 실제 데이터이며, 음향 장비의 감쇠를 흉내 내지 않는다.
- **피드:**
  - 그 시점까지 감지된 장애만 보인다(재생하면 감지 순서대로 들어온다).
  - 진행 중 장애는 원인색 띠와 스캔선(진행 중 경보)으로, 해소된 장애는 한 줄로 접는다.
  - 측정 사각지대는 점선 카드로 따로 둔다.
- **포드:**
  - 최근 2시간 p95 궤적과 150ms 기준선을 그린다.
  - 통신사 막대 높이는 체감 지연 추정(로그)이고, 흰 테두리는 경로 이상이다.
- **리본:**
  - 하루를 한 줄에 담는다. 150ms 미만은 등급색 대신 옅은 시안 농도로 칠한다. 쾌적/양호 경계에서 바코드처럼 깜빡이는 것을 막기 위해서다.
  - 리본 자체는 데이터가 같으면 다시 그리지 않는다. 커서와 미래 가림막만 HTML로 옮긴다.
  - 끌기, ←→ 5분, Shift 30분, Home, End(LIVE)로 조작한다. `role="slider"`이다.

### 색

- **크롬:** 시안 `#38e8ff`를 테두리 16%, 강조 34%, 모서리 눈금 75%로 쓴다. 브랜드 그라데이션(시안→보라)은 HUD 선과 현재 화면 버튼에만 쓴다.
- **등급:** 쾌적 `#2de2c4` · 양호 `#a3e635` · 주의 `#ffd60a` · 경고 `#ff8a1f` · 심각 `#ff2e63`.
  - 발광 화면에서는 정상도 색을 가져야 "살아 있음"이 보인다. 분석 보드는 정상을 무채색으로 둔다. 이것이 두 화면의 의도된 차이다.
- **원인:** 분석 보드 다크 팔레트를 그대로 쓴다(검증 통과, 기억 유지). 칩 글자만 흰색과 28% 섞어 밝힌다.
- **LIVE:** 시안으로 표시한다. 빨강은 '심각' 전용으로 남긴다(방송 관례보다 경보 의미를 우선한다).
- **팔레트 원본:** `palette.ts` 한 곳에 둔다. CSS는 `.cc` 루트에 주입된 `--cc-*`만 읽고, 캔버스는 같은 상수를 직접 쓴다.

## 5. 버그·교훈

- **버튼 기본 배경:** 공용 `button` 리셋은 font·color만 상속하고 배경·테두리를 지우지 않는다. 그래서 다크 color-scheme의 회색 버튼 면이 카드에 그대로 깔렸다.
  - `:where(.cc) button { background:none; border:0 … }`(특이도 0,0,1)로 리셋해 `.cc-btn` 같은 클래스 스타일이 이기게 했다.
- **클래스 충돌:** 분석 보드의 전역 `.tier-warning { background }`가 새 화면의 `tier-*` 클래스에 칠해졌다. 게이지 전체가 주황 상자가 됐다.
  - 새 화면은 `cc-t-*` / `cc-c-*`로 접두어를 붙였다. 교훈: 한 앱에 화면을 더할 때는 상태 클래스도 화면 접두어를 붙인다.
- **지역 카드 고정 방향:** 고정 방향(좌/우/상/하)은 폭에 따라 잘리거나(1920px에서 위로) 겹쳤다(1440px에서 유럽·한국).
  - 벌점 기반 자동 배치로 바꾸고 크기별 회귀 테스트를 붙였다.
- **지도 빈 띠:** 지도 비율(2.5:1)이 칸 비율(1.85:1)보다 납작해 위아래 빈 띠가 생겼다. 높이에 맞춰 줄이는 대신 폭에 맞추고 위도를 더 보여 준다.
- **입자 층 노출:** 등장 시퀀스에서 점묘 층만 가리고 입자 층은 안 가려, 스캔선보다 앞에 입자가 보였다. 두 캔버스에 같은 clip 애니메이션을 준다.
- **재생 중 스크롤:** 피드에서 재생을 누르면 지도가 화면 밖에 있었다. 재생 시작 시 지도(`.cc-hero`)를 끌어올린다(`scroll-margin-top`으로 HUD만큼 띄움).
- **시계 날짜:** 24시간 창은 전날 21시부터라 "과거 21:06"이 오늘인지 어제인지 모호했다. 다른 날이면 날짜를 붙인다(HUD·슬라이더 값 텍스트).
- **QA 대기 시간:** 등장 시퀀스가 2.2초라 기본 1.2초 대기 스크린샷에는 반쯤 그려진 화면이 찍힌다. `tools/ui-shot.cjs`에 `WAIT_MS`를 추가했다(커맨드 센터는 4500).

## 6. 백로그

- 실데이터 연결 시 노드 위치를 DC 목록에서 자동 생성하고, 변위 보정도 자동으로 한다. 지금은 6개 수동 보정에 자동 카드 배치만 있다.
- 선택된 권역의 통신사 이름이 카드에 가려질 수 있다. 라벨도 `placeCards`의 장애물로 넣는다.
- 벽 화면 모드: 일정 간격으로 권역을 자동 순회한다(사용자 조작 시 멈춤). 단, WCAG 2.2.2 정지 수단이 필요하다.
- 모바일에서는 게이지 다음에 지도가 오도록 순서를 조정한다(레일을 `display: contents`로 풀고 `order`를 쓰는 방식).
